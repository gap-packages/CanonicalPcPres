3 Limitations, credits, and citation

3.1 Limitations

The input must be a finite solvable group. Internally, the package works with pc groups. If the input is not already given as one, it is converted using IsomorphismSpecialPcGroup (Reference: IsomorphismSpecialPcGroup) before the canonical-form computation starts. One can also use IsomorphismPcGroup (Reference: IsomorphismPcGroup), but a special pc presentation can provide faster group arithmetic and therefore reduce the overall runtime of the canonical-form computation.

The implementation is intended as a framework for the algorithm in [BDH26], not as a uniformly fast isomorphism test. The principal bottlenecks are orbit computations for canonical module structures, compatible pairs, and cohomology classes. Some small groups can therefore be substantially harder than much larger groups.

3.2 Credits and citation

The implementation combines tools from several parts of computational group theory. In particular, it uses ANUPQ to compute standard presentations of finite p-groups when dealing with the maximal nilpotent quotient of the input group. It uses orb for orbit computations and hashing, and images when computing smallest orbit representatives under group actions. Please credit those packages when their functionality is relevant to published computations.

The bibliography of this manual is intentionally brief. The algorithm and its implementation build on many important results and computational tools; for the full bibliography and appropriate credits, please consult the accompanying paper [BDH26].

If you use CanonicalPcPres in published work, please cite the accompanying paper [BDH26].
