2.1 Canonical presentations

2.1-1 CanonicalPcGroup
‣ CanonicalPcGroup( G )( function )

Returns: the canonical pc group of G

Let G be a finite solvable group. This function returns the canonical pc presentation can(G). Isomorphic input groups yield equal pc presentations. If G is not already given as a pc group, the package first converts it via IsomorphismSpecialPcGroup (Reference: IsomorphismSpecialPcGroup).

gap> G := SmallGroup(36, 9);;
gap> H := CanonicalPcGroup(G);
<pc group of size 36 with 4 generators>
gap> Size(H);
36

2.2 Isomorphism attribute

2.2-1 IsomorphismCanonicalPcGroup
‣ IsomorphismCanonicalPcGroup( G )( attribute )

Returns: an isomorphism from G to its canonical pc presentation

Let G be a finite solvable group. This attribute returns an isomorphism from G to CanonicalPcGroup (2.1-1) applied to G. If necessary, G is first converted to a pc group using IsomorphismSpecialPcGroup (Reference: IsomorphismSpecialPcGroup).

gap> G := SmallGroup(24, 12);;
gap> iso := IsomorphismCanonicalPcGroup(G);;
gap> [ Source(iso) = G, Size(Range(iso)) ];
[ true, 24 ]

2.3 Information classes

2.3-1 InfoCanonicalPcPres
‣ InfoCanonicalPcPres( info class )

This info class reports the stages of the canonical-presentation computation. Level 0 suppresses these messages; higher levels provide progressively more detail.

2.3-2 InfoCanonicalPcPresTimings
‣ InfoCanonicalPcPresTimings( info class )

This info class reports timing measurements collected during the computation. Set its level to 0 for quiet, reproducible examples.

2.4 Global variables

There are two global variables, canform_USE_NEW_AUT and canform_USE_NEW_CP, that determine whether the required automorphism group and compatible pairs constructions are performed using the standard GAP functions AutomorphismGroup and CompatiblePairs or the package internal variants. By default, both variables are set true, because this often seems to improve the performance. However, there are groups (even of small orders) where setting one / both variables to false would decrease the runtime.
